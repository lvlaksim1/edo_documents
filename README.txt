EDO documents v0.3.7

Изменения v0.3.7: добавлена поддержка документа «Дополнительное соглашение» (ДОП / ADD_AGREEMENT).

ИСТОЧНИК ДАННЫХ

1. Нажатие кнопки «ЭДО»:
   все данные читаются из буфера обмена.

2. Запуск специальной ссылкой:
   буфер обмена НЕ используется; все данные читаются из URL fragment после #.
   Сервер fragment не получает.

Формат ссылки:
#__edo__?type=<ТИП>&inn=<ИНН>&number=<НОМЕР>&date=<ДД.ММ.ГГГГ>&amount=<СУММА>&file=<ПОЛНЫЙ_ПУТЬ_PDF>

Параметр amount обязателен для АКТА и СЧЁТА и не нужен для ДОГОВОРА и ДОП.
Значения параметров должны быть URL-encoded, особенно полный Windows-путь.

Поддерживаемые типы:
- АКТ / ACT -> #/document/create/ACT
- ДОГОВОР / AGREEMENT -> #/document/create/AGREEMENT
- ДОП / ADD_AGREEMENT -> #/document/create/ADD_AGREEMENT
- СЧЁТ / СЧЕТ / ACCOUNT -> #/document/create/ACCOUNT

Для АКТА, ДОГОВОРА и ДОП включаются подписи Отправителем и Получателем.
Для СЧЁТА включается только подпись Отправителем.
При успешном заполнении уведомление не показывается. При ошибке выводится сообщение.
После завершения фокус устанавливается в поле «Комментарий».


Запуск данными из ссылки (v0.3.7):
АКТ: #/document/create/ACT#__edo__?type=АКТ&inn=...&number=...&date=...&amount=...&file=...
ДОГОВОР: #/document/create/AGREEMENT#__edo__?type=ДОГОВОР&inn=...&number=...&date=...&file=...
ДОП: #/document/create/ADD_AGREEMENT#__edo__?type=ДОП&inn=...&number=...&date=...&file=...
СЧЁТ: #/document/create/ACCOUNT#__edo__?type=СЧЁТ&inn=...&number=...&date=...&amount=...&file=...
При запуске ссылкой буфер обмена не используется. Параметр file должен быть URL-encoded.
